# Slack

Sidebar themes for Slack, which takes ten colors as one comma-separated line.

## Install

1. Preferences, Themes.
2. Scroll to the bottom and click "Create a custom theme".
3. Paste the last line of `extras/slack/silkcircuit-neon.txt` into the box.

Each file also lists the ten slots by name, above the line, in case you would
rather set them one at a time.

The installer stages all five and prints the line to paste: `./install.sh`.

## What Slack lets you theme

The sidebar, its hover and active states, the presence dot, the mention badge,
and the top nav. The message pane follows Slack's own light or dark setting and
takes no custom colors, so pair the dark variants with Slack in dark mode and
dawn with light mode.
